#  Device tree of Realme GT Neo6

It was announced & released on May 2024

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Qualcomm Snapdragon 8s Gen 3 (SM8635)
CPU     | Octa-core (1x3.0 GHz Cortex-X4 & 4x2.8 GHz Cortex-A720 & 3x2.0 GHz Cortex-A520)
GPU     | Adreno 735
Memory  | 12GB/16GB RAM
Shipped Android Version | 14.0 with RealmeUI 5
Storage | 256GB/512/1024GB UFS 4.0
Battery | 5500 mAh/120w Charging
Display | LTPO AMOLED, 6.78 inches, 1264 x 2780 pixels
